# 99 Nights in the Forest: Getting Started

## Session Goal

Choose one objective related to camp upgrades, crafting, rescue objectives, and survival planning. A focused session makes it easier to measure progress and avoid wasting limited-time resources.

## Before You Start

1. Open the official experience page and read the latest update notes.
2. Check active quests, event timers, daily rewards, and prerequisites in game.
3. Set a realistic target for the session.
4. Save your starting values in the progress tracker.
5. Test unfamiliar mechanics in a low-risk situation first.

## First-Session Template

| Stage | Action |
|---|---|
| Setup | Confirm your objective and current unlocks |
| Research | Read current in-game instructions |
| Practice | Test the core mechanic without spending premium currency |
| Progress | Complete the highest-priority available objective |
| Review | Record results, blockers, and the next milestone |
